# invoice-analyst-ai web app

React + Vite + TypeScript, shadcn/ui (Nova) and Tailwind, TanStack Query and Router.

- `make api` and `make web` from the repository root (the dev server forwards `/api` to the backend)
- `make gen-api` regenerates `src/api/generated.ts` from the backend's OpenAPI description
- `npm run build` type-checks and builds; `npm run lint` runs oxlint
